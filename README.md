# FoodHub — React Restaurant Ordering Website

Responsive React + Vite frontend for CSCI426 Project Phase 1.

## Setup
```bash
npm install
npm run dev
```

## Production check
```bash
npm run build
```

## Features
Nine pages, 24 menu products, filters, product customization, shopping cart, checkout form, order status, contact form, dark mode, responsive design.

## Technical limitations
This is a frontend-only student project. Orders and status changes are stored in browser localStorage and do not reach a restaurant. The contact form does not send email, and the newsletter is not connected. No payment processing is available. Connect a real backend and contact service before accepting customer orders.

## Photography
Product and category photographs are loaded from Unsplash image URLs and require an internet connection. Original local SVG illustrations remain as offline fallbacks. Check image licensing and replace or self-host photos before production.

## Deployment
Deploy to Vercel or Netlify; source code and commit history belong on GitHub.
